# Sales-Performance-Analysis
# Sales Performance Analysis using Python and SQL

## Project Objective
Analyze retail sales data to identify trends in customer behavior, product categories, and regional performance.

## Tools Used
- Python
- pandas
- matplotlib
- SQL
- Google Colab

## Dataset Features
The dataset includes:
- Order ID
- Order Date
- Ship Mode
- Customer Name
- Segment
- Region
- Category
- Sub-Category
- Product Name
- Sales

## Analysis Performed
- Data cleaning and preprocessing
- Sales analysis by category, region, and segment
- Monthly sales trend analysis
- Identification of top performing products
- SQL queries for business insights

## Key Insights
- Sales differ across categories and regions
- Consumer segment contributes significantly to total sales
- Some products consistently generate high revenue
- Monthly trends indicate variations in demand
